# NEXORA Core

Build the foundation of a production quality SaaS application called NEXORA.

NEXORA is a Business Operations Intelligence Platform designed for small, medium, and large organizations.

Use the existing Lovable stack and Supabase.

Create a polished modern enterprise UI with excellent UX.

Requirements:

1. Create the main application shell.

2. Create responsive sidebar navigation.

3. Create top navigation/header.

4. Create dashboard placeholder.

5. Create navigation sections for:

   Dashboard

   Sales

   Inventory

   CRM

   Employees

   Projects

   Finance

   Analytics

   Automation

   AI Assistant

   Settings

6. Use reusable components instead of duplicated UI.

7. Create a consistent design system.

8. Make the application responsive for desktop, tablet, and mobile.

9. Add light and dark mode.

10. Do not implement the business modules yet.

11. Do not modify unrelated functionality.

12. Prepare the architecture so future modules can be added cleanly.

Focus only on the foundation and application shell.

Do not generate unnecessary mock features.

with great ui and ux design.
